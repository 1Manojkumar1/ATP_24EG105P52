# Week 3 - Databases & Authentication

This directory focuses on connecting Node.js/Express applications to MongoDB and implementing secure user authentication.

## Contents
- **`UserProductAPI-with-authAndDB/`**: A complete REST API demonstrating MongoDB integration (via Mongoose), user authentication workflows, and structured routing (`APIs`, `models`, `middlewares`). Features include:
  - User creation, JWT authentication, and protected endpoints via HttpOnly cookies.
  - Dedicated MongoDB models and schema validation for Users and Products.
  - Express application architecture with routing split by resource.
  - See the detailed [README](file:///C:/MERN/NODE/MERN_Assignments/Week%203/UserProductAPI-with-authAndDB/README.md) inside the project folder for specific endpoint usage, database schema properties, and setup instructions.
- **`mongodbPractice.txt`**: A reference file containing raw MongoDB shell queries. It includes practice exercises for basic CRUD operations, array manipulations (`$push`, `$pop`), and modifying complex nested objects (e.g., employee skills and experiences).
