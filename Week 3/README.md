# Week 3 - Databases & Authentication

This directory focuses on connecting Node.js/Express applications to MongoDB and implementing secure user authentication.

## Contents
- **`UserProductAPI-with-authAndDB/`**: A complete REST API demonstrating MongoDB integration (via Mongoose), user authentication workflows, and structured routing (`APIs`, `models`, `middlewares`).
- **`mongodbPractice.txt`**: A reference file containing raw MongoDB shell queries. It includes practice exercises for basic CRUD operations, array manipulations (`$push`, `$pop`), and modifying complex nested objects (e.g., employee skills and experiences).
