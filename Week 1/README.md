# Week 1 - JavaScript Basics

This directory contains introductory JavaScript assignments and practice scripts.

## Contents
- **Number Comparisons**: Scripts to find the largest among 2 or 3 numbers (`bigIn2Nums.js`, `bigIn3Nums.js`, etc.).
- **Array Operations**: Scripts to process arrays of marks, including finding the sum, least marks, and specific indexes (`sumOfMarks.js`, `leastMarks.js`, `findIndexOfMarks.js`).
- **Employee Records**: Practice with object and array manipulations (`emp_record_operations.js`).

## Usage
Run any of the scripts using Node.js:
```bash
node <filename.js>
```
