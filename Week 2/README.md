# Week 2 - Advanced JavaScript & Node.js Projects

This directory contains a mix of standalone JavaScript practice scripts and larger, structured Node.js projects focusing on advanced JavaScript concepts, object/array manipulation, and foundational backend development.

## Sub-Projects (Folders)
Each of these subdirectories contains its own `README.md` with detailed information:
- **`Shopping-Cart-System/`**: A simulated backend E-Commerce system demonstrating ES6 modules, inventory management, and cart operations.
- **`Task-Manager/`**: A modular Node.js application for managing tasks, highlighting separation of concerns and validation.
- **`UserProductAPI/`**: An introductory Express.js REST API utilizing in-memory arrays to perform CRUD operations on Users and Products.

## Standalone Scripts (Files)
A collection of scripts practicing various JavaScript paradigms, such as object references, higher-order functions, and business logic implementation:
- **Copying & Objects**: `shallowCopy.js`, `deepCopy.js`, `copyAndExtend.js`
- **Business/System Logic**: `LibraryManagement.js`, `bankTransaction.js`, `empPayrollProcessor.js`, `examPortal.js`, `movieRecommendation.js`, `shoppingCart.js`, `studentPerformance.js`
- **Utilities**: `otpCountdown.js`, `restParamSum.js`, `updateUser.js`

## Usage
To run any of the standalone scripts, use Node.js in your terminal:
```bash
node <filename>.js
```
For the larger sub-projects, navigate into their respective directories and follow their specific instructions.
