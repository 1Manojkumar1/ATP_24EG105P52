# Employee App - Frontend

The frontend client for the Employee Management Application, built with React and Vite.

## Overview
This application serves as the user-facing interface for managing employee records. It communicates with the separate backend API to perform CRUD operations (Create, Read, Update, Delete) on employee data and renders it in an organized, interactive UI (such as data tables and input forms).

## Setup & Running

1. **Install dependencies**:
   ```bash
   npm install
   ```
2. **Start the development server**:
   ```bash
   npm run dev
   ```
3. Open the provided `localhost` URL in your browser.

*Note: Ensure the `employee-app` backend server is running simultaneously so the frontend API requests can successfully resolve.*
