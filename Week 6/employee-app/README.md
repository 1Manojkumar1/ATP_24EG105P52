# Employee App (Full-Stack)

A full-stack application structure containing a separate frontend client and backend API for managing employee records.

## Overview
This project is divided into two distinct parts to demonstrate a decoupled architecture:
- **`frontend/`**: The React-based client interface for users to interact with employee data.
- **`backend/`**: The Node.js/Express server that handles API requests, database interactions, and business logic.

## Setup & Running
Because this is a full-stack application, both the frontend and backend must be run simultaneously.

1. **Backend**:
   - Navigate to the `backend/` directory.
   - Install dependencies (`npm install`).
   - Start the server (`npm start` or `npm run dev`).
2. **Frontend**:
   - Navigate to the `frontend/` directory in a separate terminal.
   - Install dependencies (`npm install`).
   - Start the development server (`npm run dev`).
