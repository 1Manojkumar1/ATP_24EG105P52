# Context Counter App

A React application built with Vite that demonstrates state management using the React Context API.

## Overview
This project provides an example of how to avoid "prop drilling" by utilizing `createContext` and `useContext`. It implements a simple counter (increment, decrement, reset) where the state is accessible from anywhere in the component tree.

## Setup & Running
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
