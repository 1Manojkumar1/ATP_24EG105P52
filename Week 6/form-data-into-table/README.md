# Form Data Into Table

A React application built with Vite that demonstrates form handling and dynamic rendering.

## Overview
This assignment focuses on capturing user input via controlled form components and storing that data in component state. The application then maps over the state array to render the submitted data into an HTML table structure dynamically.

## Setup & Running
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
