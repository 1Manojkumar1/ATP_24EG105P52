# Week 6 - Advanced React & Full-Stack Integration

This directory covers advanced React state management and full-stack application development.

## Projects
- **`context-counter-app/`**: A React application demonstrating global state management using the React Context API.
- **`form-data-into-table/`**: A React application focusing on form handling, controlled components, and rendering user input into a dynamic data table.
- **`employee-app/`**: A full-stack application containing both a backend API and a frontend React client to manage employee records.

## Usage
Navigate to each specific project directory to see detailed setup and execution instructions.
