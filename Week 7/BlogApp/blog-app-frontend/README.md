# Blog App - Frontend

The frontend client for the Blog Application, built with React and Vite.

## Overview
This React application provides the user interface for the Blog App. It handles client-side routing, user authentication state (login/register forms), and interfaces with the backend REST API to fetch, create, and display blog posts dynamically.

## Setup & Running

1. **Install dependencies**:
   ```bash
   npm install
   ```
2. **Environment Variables**:
   Ensure you have configured any necessary environment variables (e.g., API base URL pointing to your backend) if required.
3. **Start the development server**:
   ```bash
   npm run dev
   ```
4. Open the provided `localhost` URL in your browser.

*Note: Ensure the `blog-app-backend` server is also running simultaneously to fetch data successfully.*
