# Blog Application (MERN Stack)

A full-stack Blog Application built using the MERN stack (MongoDB, Express, React, Node.js). 

## Project Structure
This application is separated into two distinct projects to demonstrate a decoupled full-stack architecture:
- **`blog-app-frontend/`**: The React-based user interface where users can view, create, and manage blog posts.
- **`blog-app-backend/`**: The Node.js and Express REST API that handles database interactions, authentication, and business logic.

## Getting Started
To run this application locally, you will need to start both the backend and frontend servers simultaneously. Navigate into each directory and follow the setup instructions in their respective `README.md` files.
