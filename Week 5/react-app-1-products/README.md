# React App 1: Products

A React application built with Vite that focuses on displaying and managing product data.

## Overview
This assignment demonstrates how to build reusable React components to display a list of products, typically passing data via props and structuring an e-commerce-style product grid or list.

## Setup & Running
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the provided `localhost` URL in your browser.
