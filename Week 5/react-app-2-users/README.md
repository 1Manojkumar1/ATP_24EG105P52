# React App 2: Users

A React application built with Vite that focuses on rendering user data.

## Overview
This assignment demonstrates component architecture by creating user lists or cards, practicing how to map over arrays of data and pass information down to child components using props.

## Setup & Running
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the provided `localhost` URL in your browser.
