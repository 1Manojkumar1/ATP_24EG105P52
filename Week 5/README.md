# Week 5 - UI & Frontend Fundamentals

This week covers both core web design (HTML/CSS Layouts and Tables) and an introduction to component-based frontend development using React.

## Directory Structure
- **`Layouts/`**: Practice with CSS Flexbox and Grid layouts.
- **`Tables/`**: Practice with HTML tables and styling.
- **`react-app-1-products/`**: A React application focusing on rendering product data and building UI components for an e-commerce view.
- **`react-app-2-users/`**: A React application focusing on user lists, rendering user data, and managing basic state or props.
- **`react-app-3-profiles/`**: A React application focusing on building detailed profile cards or profile views.

## Running the React Apps
Each React app is bootstrapped with [Vite](https://vitejs.dev/). To run any of them, navigate to the specific app folder and run:
```bash
npm install
npm run dev
```
