# Week 5 - HTML Tables and CSS

This directory contains assignments focusing on HTML table structures and styling them with CSS.

## Contents
- `table1.html` / `table1.css`
- `table2.html` / `table2.css`
- `table3.html` / `table3.css`

These files demonstrate how to structure tabular data and apply styling for better readability and presentation.

## Usage
Open any of the HTML files directly in a web browser to view the styled tables.
