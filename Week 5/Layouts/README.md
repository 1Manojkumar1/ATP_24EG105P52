# Week 5 - CSS Layouts

This directory contains practice assignments for building page layouts using HTML and CSS (Flexbox/Grid).

## Contents
- `layout1.html` / `layout1.css`
- `layout2.html` / `layout2.css`
- `layout3.html` / `layout3.css`
- `layout4.html` / `layout4.css`

Each pair demonstrates a different layout structure and CSS techniques.

## Usage
Open any of the HTML files directly in a web browser to view the layouts.
