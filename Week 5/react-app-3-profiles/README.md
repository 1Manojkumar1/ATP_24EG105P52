# React App 3: Profiles

A React application built with Vite that focuses on building user profile views.

## Overview
This assignment practices creating detailed profile cards, likely combining image rendering, styling, and structured data presentation within React components.

## Setup & Running
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the provided `localhost` URL in your browser.
